# SOLIDWORKS 渐开线齿轮生成器

一个 SOLIDWORKS 插件，生成**真正的渐开线圆柱齿轮** —— 包含齿条刀具扫出的真实 trochoid 齿根
过渡曲线，根切如实出现，而不是拿一个圆角糊过去。

*[English](README.md)*

---

## 为什么再造一个

SOLIDWORKS 用户能拿到的齿轮工具，齿廓基本都是近似的。这个不是：

| 工具 | 齿廓 | 齿根过渡 | 根切 |
|---|---|---|---|
| SOLIDWORKS Toolbox | **等半径圆弧** —— Dassault [官方明说](https://help.solidworks.com/2026/english/SolidWorks/toolbox/c_Gears.htm)"不是可用于制造的真渐开线齿轮" | 无 | 无 |
| Fusion 360 官方 SpurGear 脚本 | 渐开线，10 点 | **直线**连到齿根圆 | 无（z ≥ 42 时几何直接是错的）|
| Onshape Spur Gear | 渐开线 | 约束求解器凑的内切圆 | 无 |
| OpenSCAD 各库 | 折线逼近 | 基本没有（BOSL2 除外）| 仅 BOSL2 |
| 在线 DXF 生成器 | 折线逼近 | 无 | 无 |
| **本项目** | **解析渐开线** | **真齿条刀具包络（trochoid）** | **如实建模** |

如果你要线切割、3D 打印、做运动仿真、或者分析侧隙和啮合，这个差别是实打实的。

## 有什么

**一个原生插件。** 功能区自己的选项卡 + 真正的属性管理器面板，改数字时计算结果实时更新，
根切 / 齿顶变尖 / 齿顶太薄会当场警告。点一下出实体，特征树干净可编辑：

```
齿坯（拉伸） → 一个齿槽（切除） → 圆周阵列 ×z → 内孔 + 键槽（切除）
```

模数、齿数、变位、公法线、量棒距等自动写入模型自定义属性，出工程图可直接引用。

**另外两件配套：**

- `macro/` —— 自包含的 VBA 宏。粘进 VBA 编辑器按 F5，零安装；在不能注册插件的机器上很有用。
- `web/gear.html` —— 浏览器参数面板：实时齿形预览、全部几何量、公法线与量棒距、DXF 导出（R12）。
  离线可用，无任何依赖。

## 功能

- 直齿与斜齿（斜齿生成端面齿形，并给出所需扭转角）
- 外齿轮与内齿圈
- 变位系数，含根切与齿顶变尖检测、齿顶圆自动收敛
- 齿顶高 / 顶隙 / 刀尖圆角系数可调
- 内孔，可选 **GB/T 1095** 轮毂平键槽
- 跨 `k` 齿公法线 `W`、量棒（球）距 `M`、弦齿厚
- DXF R12 导出（网页面板）

## 编译与安装

SOLIDWORKS 的 interop 程序集**不随本仓库分发**，请从你自己的安装目录复制：

```
<SOLIDWORKS 安装目录>\api\redist\
    SolidWorks.Interop.sldworks.dll
    SolidWorks.Interop.swconst.dll
    SolidWorks.Interop.swpublished.dll
```

然后：

```bat
cd addin
build.cmd
```

`build.cmd` 会从注册表找到 SOLIDWORKS，把三个 interop DLL 复制到输出目录，编译出
`GearWorks.dll`。接着**以管理员身份**运行：

```bat
install.bat
```

重启 SOLIDWORKS。打开零件文档后，功能区会出现 **齿轮工具** 选项卡。
没出现的话去 *工具 → 插件* 里勾选。

> 安装目录的绝对路径会被写进注册表，装完**不要移动这个文件夹**。
> 要挪：先跑 `uninstall.bat`，移动，再跑 `install.bat`。

卸载：以管理员身份运行 `uninstall.bat`，然后删掉文件夹。

## 齿廓怎么算的

齿廓由两段数学性质不同的曲线组成，在自然相切处衔接。

**渐开线段** —— 解析式，精确：

```
θ(ρ) = sT/(2r) + inv(αt) − inv(αy)，   αy = acos(rb/ρ)，   inv(a) = tan a − a
```

**齿根过渡段** —— 齿条刀具在节线上纯滚动时，刀尖圆角扫出的包络。刀具平移 `u` 时齿轮转过
`φ = u/r`。由啮合基本定律，接触点法线过节点，所以刀尖圆角上的接触点就是圆心沿
「节点→圆心」方向外推一个圆角半径：

```
Cw = (Cx + u, Cy)              刀尖圆角圆心（刀具系）
P  = Cw + rc · Cw/|Cw|         接触点
```

`u` 从 `−Cx`（圆角与刀顶平面相切，落在齿根圆上）扫到 `Cy/tan αt − Cx`
（圆角与刀具直线段相切，**恰好落在渐开线上**），就是完整的过渡曲线。

**根切是自然掉出来的**：扫描过程中，若某个 trochoid 点在 `ρ > rb` 处落到了渐开线内侧
（`θ_trochoid < θ_involute(ρ)`），说明刀具在那里已经把渐开线齿面切掉了。
在交点截断，渐开线从该半径重新开始。没有特判、没有经验公式 —— 根切出现是因为它物理上真的发生了。

## 已知限制

1. **斜齿生成的是端面齿形的直齿体。** 要真螺旋齿面，对拉伸体加【扭曲】特征 ——
   面板会算好所需扭转角（`b·tanβ/r`）告诉你。
2. **内齿圈齿根过渡是相切圆弧近似**（渐开线齿廓部分是精确的）。真实内齿过渡由插齿刀展成，
   形状取决于插齿刀齿数，常规制图用不到。内齿路径已离线验证几何闭合，但**尚未在 SOLIDWORKS 里实机跑过**。
3. 未做：干涉校核、齿根弯曲/接触强度、精度等级与公差带、人字齿、锥齿轮、蜗轮蜗杆。
4. 变位系数不自动优化，由使用者给定。
